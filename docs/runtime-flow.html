主线从桌面入口 electron/service.ts::sendUserMessage() 开始，穿过上下文构建、记忆召回、brain loop、工具执行、validation 修复闭环，最后再写回 SQLite 与 artifact。

关键入口文件

  • electron/service.ts：桌面端 run 发起与收尾
  • src/app/agent.ts：一次 Agent.run 的总入口
  • src/brain/loop.ts：主循环与 workingMemory 更新

三层“记忆”边界

  • Persistent memory：SQLite durable facts
  • Context bundle：本轮 prompt 压缩后的可见上下文
  • Working memory：runLoop 内部运行态

最关键的 harness 特征

  • 写文件后自动补 validation
  • validation 失败会提炼成 repair guidance
  • 下轮模型看到 history + workingMemory，而不只是聊天记录
